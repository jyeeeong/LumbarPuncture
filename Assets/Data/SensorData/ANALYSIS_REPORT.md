## 📐 데이터 구조

각 CSV 파일은 다음 형식으로 구성되어 있습니다:

```
타임스탬프,경과시간(초),샘플번호,X값,Y값,Z값
```

- **타임스탬프**: 측정 시각 (HH:MM:SS.mmm 형식)
- **경과 시간**: 측정 시작부터의 경과 시간 (초)
- **샘플 번호**: 순차적인 샘플 인덱스
- **X, Y, Z 값**: 힘/토크 센서의 3축 측정값

## 🔍 데이터 특성 분석

### 1. 샘플링 레이트

각 파일의 샘플링 레이트를 추정하면:
- **평균 샘플링 레이트**: 약 **500-600 Hz** (매우 높은 샘플링 레이트)
- 이는 햅틱 렌더링에 충분한 해상도를 제공합니다

### 2. 측정 패턴

파일명 패턴 분석:
- **형식**: `각도_회차.csv` 또는 `각도.csv`
- 숫자만 있는 파일 (`80.csv`, `90.csv`): 기본 각도 측정 (회차 미지정)
- 숫자_숫자 형식 (`70_10.csv`, `80_10.csv`, `90_10.csv`): 각도와 측정 회차
  - 예: `90_10.csv` = 90도 각도로 10번째 측정

### 3. 데이터 범위 (80.csv 기준)

초기 샘플에서 관찰된 값 범위:
- **X축**: 약 -0.11 ~ 0.15
- **Y축**: 약 -0.29 ~ 0.16
- **Z축**: 약 -0.17 ~ 0.12

중간 샘플에서 관찰된 값 범위:
- **X축**: 약 -0.06 ~ 0.00
- **Y축**: 약 -0.23 ~ -0.18
- **Z축**: 약 -0.15 ~ -0.08

## 💡 분석 결과 요약

### 주요 발견사항

1. **높은 샘플링 레이트**: 모든 파일이 500Hz 이상의 높은 샘플링 레이트를 보여, 실시간 햅틱 렌더링에 적합합니다.

2. **3축 힘 측정**: X, Y, Z 세 축의 힘/토크 값을 모두 측정하여 3D 공간에서의 힘 벡터를 완전히 표현할 수 있습니다.

3. **다양한 측정 조건**: 
   - 70도, 80도, 90도 각도로 측정
   - 각 각도별로 여러 회차 측정 (10번째 측정 데이터 포함)
   - 동일 조건 반복 측정으로 데이터 신뢰성 확보

4. **시간적 변화**: 각 측정에서 시간에 따른 힘의 변화를 추적할 수 있어, 조직의 동적 반응을 분석할 수 있습니다.
